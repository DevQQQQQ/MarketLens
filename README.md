## 🌟 为什么选择 MarketLens？

作为程序员，在工作专注编码时，经常需要兼顾自选资产（股票、指数、加密代币、链上新币）的盘面异动。频繁切换桌面炒股炒币软件不仅打断工作心流，而且容易被旁人察觉。

**MarketLens** 将全市场行情深度融合进 VS Code 编辑器中：

- 🌲 **五合一全能行情**：A股、港股、美股、Binance 主流币、Alpha 链上新币一站式聚合，告别多软件频繁切换；
- 🕶️ **极致专注与安全隐秘**：配备老板键一键隐藏、终端日志伪装摸鱼、颜色脱敏模式、休市自动节流；
- 📊 **状态栏无缝轮播**：底部状态栏按需滚动行情，支持各板块独立开关精细控制；
- 🛡️ **网络安全与防审计**：境内正规源直连，Web3 接口强制走本地代理，杜绝公司网关留痕。

## ✨ 核心功能与特性

### 1. 🌐 全市场资产五合一覆盖

- 🇨🇳 **A股市场 (沪深京)**：
    - 直连境内正规金融源，零延迟实时拉取；
    - 覆盖上证、深证、北交所全市场股票与各大指数（如上证指数、沪深300等）；
    - 智能交易时段判定：仅在工作日交易时段轮询，收盘及周末自动休眠节流。
- 🇭🇰 **港股市场 (HK Stocks)**：
    - 覆盖恒生指数、腾讯控股、美团、阿里巴巴、小米等核心资产；
    - 支持标准 5 位代码识别（如 `00700`、`03690`），多币种港币（`HK$`）专属结算展示。
- 🇺🇸 **美股市场 (US Stocks)**：
    - 覆盖纳斯达克、标普500、道琼斯全市场标的及指数；
    - 苹果 (`AAPL`)、英伟达 (`NVDA`)、特斯拉 (`TSLA`)、微软 (`MSFT`)、纳指 (`.IXIC`) 实时追踪；
    - 智能识别北京时间夜间交易时段与盘后展示。
- 🟡 **Binance 币安主流代币**：
    - 覆盖 BTC、ETH、SOL、BNB、DOGE 等主流加密资产与山寨代币；
    - 24 小时全天候无间断拉取最新价格、日内涨跌幅及波动幅度。
- 🦄 **Alpha 链上 DEX 聚合 (全链新币)**：
    - 集成 DexScreener 全球去中心化交易所聚合行情；
    - 支持 Solana、BSC、Base、以太坊、Arbitrum 等主流公链；
    - 只需粘贴代币合约地址，即可秒级识别代币名称、价格、24h 涨跌及流动性池深度。

### 2. 🖱️ 看板与标的自由管理

- **长按鼠标拖拽排序**：在侧边栏任意长按标的，即可在当前板块上下拖动调整展示顺序；
- **一键置顶标的**：鼠标悬停在资产上，点击左侧的 **🔝 置顶** 按钮，即可瞬间将关注资产移动至当前分组第一行；
- **快速删除与清理**：悬停点击 **🗑️ 删除** 图标，即可秒级移除单只标的；
- **一键清空自选标的**：在设置中心支持一键将所有默认预设标的置空，保留板块结构，方便从零自由建立属于自己的自选库；
- **一键恢复出厂预设**：随时一键重置回系统初始预设资产库（包含各大板块经典代表性标的）。

---

### 3. 📊 底部状态栏平滑轮播系统

- **平滑无缝轮播**：数据刷新与轮播定时器解耦，杜绝每 5 秒数据更新造成的轮播重置与口吃现象；
- **全部标的参与轮播（总控开关）**：在【通用设置】中一键控制底部状态栏是否展示行情，关闭后状态栏彻底隐藏；
- **各板块独立轮播开关**：
    - 支持单独控制 `A股`、`港股`、`美股`、`Binance`、`Alpha` 标的是否进入状态栏轮播；
    - 例如：可设置左侧看板查看全部资产，但底部状态栏仅循环播放你最关心的美股或币安代币。

---

### 4. 🕶️ 极致摸鱼与安全脱敏

- 🕶️ **老板键一键隐藏 / 恢复 (`Ctrl + Alt + M` / `Alt + M`)**：
    - 瞬间隐藏左侧自选看板、清空底部状态栏行情、关闭设置面板；
    - 再次按下快捷键，所有看板与状态栏立即恢复，响应毫秒级。
- 🎭 **伪装摸鱼模式 (`Ctrl + Alt + K` / `Alt + K`)**：
    - 将底部状态栏行情伪装成极度真实的编译日志或 Git 分支状态（例如：`git:(main) build: 65.2k`），路过者毫无察觉。
- ⚪ **颜色脱敏模式 (`Ctrl + Alt + C` / `Alt + C`)**：
    - 一键关停刺眼的“红涨绿跌”或“绿涨红跌”视觉刺激；
    - 所有数值采用编辑器默认的中性前景色，低调优雅。
- 💤 **交易时段智能休眠节流**：
    - 各大市场休市与周末期间自动停止轮询，大幅减少 CPU 占用与无意义网络流量。

### 5. 🛡️ 网络访问、数据源清单与防公司审计隐私说明

针对在企业办公环境（存在网关流量审计、DPI 深度包检测、DNS 日志留痕）下的开发者，MarketLens 从底层架构上提供了透明、安全且防穿透的网络设计：

#### 📡 全球行情数据源透明清单（公开、免鉴权、零个人凭证）
| 资产板块 | 接入上游开放数据源 | 官方域名 | 协议与认证 | 默认网络策略 |
| :--- | :--- | :--- | :--- | :--- |
| **A股** (沪深京) | 腾讯证券开放金融行情接口 | `qt.gtimg.cn` | HTTPS / HTTP (免登录无状态) | 境内直连（零延迟） |
| **港股** (恒生核心) | 腾讯证券开放金融行情接口 | `qt.gtimg.cn` | HTTPS / HTTP (免登录无状态) | 境内直连（零延迟） |
| **美股** (三大指数/个股) | 腾讯证券开放金融行情接口 | `qt.gtimg.cn` | HTTPS / HTTP (免登录无状态) | 境内直连（零延迟） |
| **Binance** (加密货币) | 币安现货公开市场 API | `api.binance.com` | HTTPS (公开只读接口) | 建议开启强制代理 |
| **Alpha** (全链DEX) | DexScreener 官方聚合 API | `api.dexscreener.com` | HTTPS (公开只读接口) | 建议开启强制代理 |

#### 🔒 网络隐私与防公司审计防护原理
1. **绝对零凭证与零数据上传**：
   - 插件**不需要任何 API Key、Token 或用户账号密码**；
   - 绝不收集、记录或上传用户的代码、工作区、设备指纹或自选标的列表，所有自选资产仅安全保存在本地 VS Code 的 `settings.json` 中。
2. **强制代理底层物理阻断（杜绝直连降级）**：
   - 当为特定板块（如 Binance、Alpha）开启【强制代理】后，网络层会严格仅向本地回环代理端口（如 `http://127.0.0.1:7890`）投递数据包；
   - **绝对杜绝静默直连**：若代理客户端未启动或端口连不上，插件会主动熔断拦截并报错，**绝不会为了获取数据而偷偷退化为直连访问**；
   - **公司网关留痕防御**：目标域名解析（DNS）与 TLS 握手均在本地代理软件及代理节点内部完成，企业防火墙和网络审计设备只能观察到 VS Code 进程与本地环回地址（`127.0.0.1`）之间的通信，无法捕获到 `binance.com` 等敏感域名的 SNI 握手特征。
3. **一键代理自动探测与自适应探测池**：
   - 设置中心提供 `⚡ 探测代理` 按钮，自动识别本机常见代理端口（如 Clash `7890`/`7897`、v2rayN `10808`/`10809`、sing-box `2080` 等），一键配置零门槛；
   - 具备 30 秒全局探测冷却与熔断保护，代理离线时绝不引发请求风暴。
4. **交易时段休眠节流**：
   - A股、港股、美股在非交易时段及周末全自动停发轮询请求，进一步规避不必要的网络发包特征。

## 🚀 快速上手

### 1. 添加自选资产

点击自选看板顶部的 **`+`** 按钮，输入框具备**智能多格式正则解析**：

- **添加 A 股**：输入 6 位数字（如 `600519` 贵州茅台，或带前缀 `sh600519`、`sz000001`），自动归入 `A股` 分组；
- **添加港股**：输入 5 位数字或带前缀（如 `00700` 腾讯控股、`hk03690` 美团），自动归入 `港股` 分组；
- **添加美股**：输入美股 Ticker（如 `AAPL` 苹果、`NVDA` 英伟达、`TSLA` 特斯拉、指数 `.IXIC`），自动归入 `美股` 分组；
- **添加主流币**：输入币对名称（如 `BTCUSDT`、`ETHUSDT`、`SOLUSDT`），自动归入 `Binance` 分组；
- **添加链上新币**：粘贴 EVM 合约地址（`0x...` 42位）或 Solana Mint 地址（32~44位），自动归入 `Alpha` 分组并拉取池子行情。

### 2. 调整顺序与置顶

- **拖拽排序**：在侧边栏鼠标按住任意资产直接拖拽上下移动；
- **一键置顶**：鼠标悬停在资产上，点击 `🔝` 图标即可瞬间将其置顶到当前分组第一位。

### 3. 查看丰富详情悬停气泡

将鼠标悬停在任意自选标的上，即可弹出专业详情气泡：

- 今开、昨收、当日最高价、最低价；
- 成交量、成交额、换手率（股票）；
- 链上全网流动性池深度（DEX 资产）。
